Privacy Policy – AI Art Publisher

Last updated: November 2026

1. Purpose of the Application

AI Art Publisher is a personal, locally-run tool designed to help a single user publish their own artwork to various online platforms. The application runs on the user's own computer and is not distributed, shared, or made available to any third party.

2. Data Collected

AI Art Publisher does not collect, store, or process any personal data from any user other than its own operator. No analytics, no tracking, no cookies, and no external data transmission occur beyond the API calls required to publish content to the platforms chosen by the operator.

3. Access to Pinterest Data

The application uses the Pinterest API solely to:

  • Authenticate the operator's own Pinterest account;
  • Read the list of the operator's own boards in order to obtain the target board identifier;
  • Create Pins on the operator's own boards.

No data belonging to other Pinterest users is accessed, read, or processed. Authentication tokens are stored locally on the operator's machine and are never shared with any third party.

4. Data Sharing

AI Art Publisher does not sell, rent, or share any data with third parties. All operations are performed locally on the operator's device.

5. Data Retention

Authentication tokens are stored locally and can be deleted at any time by the operator by removing the local token file. No other data is retained.

6. Contact

For any question regarding this privacy policy, please contact the application operator via their Pinterest profile.
